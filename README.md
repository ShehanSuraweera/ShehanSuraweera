# 🚧 Currently Building — OpsPilot

### AI-powered incident management for engineering teams

**OpsPilot** is a project I'm building to explore the intersection of **backend engineering, DevOps, cloud infrastructure, and AI agents**.

The goal is to help engineering teams investigate production incidents faster.

Alerts become incidents, an AI-assisted workflow investigates relevant logs, metrics, and system state, and suggested remediation remains under **human approval** before execution.

### Current Stack

`Go` · `Python` · `FastAPI` · `PostgreSQL` · `pgvector` · `Redis` · `Next.js` · `Docker`

### Roadmap

| Version  | What it adds                                                                  | Status         |
| -------- | ----------------------------------------------------------------------------- | -------------- |
| **v0.1** | Go API, authentication, RBAC, idempotent alert ingestion + Python RAG service | 🔨 In Progress |
| **v0.2** | PostgreSQL tuning, Redis, transactional outbox, event-driven workers          | ⏳ Planned      |
| **v0.4** | AWS ECS Fargate, RDS, SQS, S3, CloudFront, keyless CI/CD                      | ⏳ Planned      |
| **v0.5** | Kubernetes on EKS, Helm, autoscaling, network policies                        | ⏳ Planned      |
| **v0.6** | Terraform, OpenTelemetry, Prometheus, Grafana, threat modeling                | ⏳ Planned      |
| **v0.8** | AI agent + MCP server with permission tiers and human approval                | ⏳ Planned      |
| **v1.0** | End-to-end AIOps workflow with Bedrock Guardrails and evaluations             | ⏳ Planned      |

### 🔗 [Linkr — URL Shortener with Analytics](https://github.com/ShehanSuraweera/Linkr)

**Backend engineering · Go + PostgreSQL + Redis**

A production-oriented URL shortener with authentication, link management, click analytics, caching, rate limiting, and observability.

* ⚡ Asynchronous click-processing pipeline with batched database writes
* 🚀 L1 LRU + Redis tiered caching with circuit-breaker support
* 🔐 JWT authentication and secure short-code generation
* 📊 Per-link analytics by day, device, browser, and referrer
* 🩺 Prometheus metrics with liveness and readiness endpoints
* 🧪 Concurrent testing with Go's race detector
* 🐳 Full-stack Docker Compose environment
* 📐 Architecture documentation and recorded design decisions

`Go` · `Gin` · `PostgreSQL` · `pgx` · `Redis` · `Next.js` · `TanStack Query` · `Docker` · `Prometheus`
